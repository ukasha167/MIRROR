# Claude harness instructions

Read and follow [AGENTS.md](./AGENTS.md) and [plan.md](./plan.md) before starting any task.

When running on a Claude harness:
* Use **Haiku (high effort)** for Tier 1 tasks: scaffolding, cloning or vendoring repositories into `third_party/`, and build configuration.
* Use **Sonnet (medium effort)** for Tier 2 tasks: implementing Rust crates, Swift modules, Android Kotlin services, and unit tests.
* Use **Opus (high effort)** for Tier 3 tasks: zero-copy media and USB pipelines, cryptographic pairing, `FLAG_SECURE` bypass internals, and all architecture or code reviews.
